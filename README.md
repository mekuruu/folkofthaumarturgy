![Silverwood Thaumium/Copper Wrench-capped Want](assets/silverwoodthaumium_wrenchcappedwand.svg)

Assortment of various mods, picked with no further criteria than "it works". Contains heavily opinionated balance changes for the creator's own fun. 

Files under `serverscripts/` are some utilities we wrote ourselves to sync lwjgl3ify and Unsup, along with starting up the server (`java9args.txt` taken from [lwjgl3ify's repo](https://github.com/GTNewHorizons/lwjgl3ify)). Requires Python 3 and bash; feel free to use and modify them for yourself.
